Automatic Token Capacity

Max Tokens Cap is calculated from the selected input size and Token Bit Size. A token occupies whole bytes, so the byte width is ceil(i / 8); this does not perform true bit-level tokenization.

Input

No file selected (0 bytes).

Token settings

Calculated as ceil(file bytes / ceil(i / 8)). Updates when the file or bit size changes.

Select a file or choose a token bit size to calculate capacity.
